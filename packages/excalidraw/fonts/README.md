# Bundled fonts

Fonts are separate works from the code and are not covered by the repository's MIT license. Each family directory carries the license text that applies to its font files. The build-time source TTFs for the server-side export path live in `scripts/woff2/assets/` with their license texts alongside.

| Family | Role | License |
| --- | --- | --- |
| Excalifont | current default, hand-drawn | SIL OFL 1.1 (Excalidraw) |
| Nunito | current default, normal | SIL OFL 1.1 (The Nunito Project Authors) |
| Comic Shanns Mono | current default, code | MIT (Shannon Miwa and contributors) |
| Virgil | legacy hand-drawn, kept so old files render correctly | SIL OFL 1.1 (Ellinor Rapp) |
| Cascadia Code | legacy code, kept so old files render correctly | SIL OFL 1.1 (Microsoft) |
| Lilita One | charts feature | SIL OFL 1.1 (Juan Montoreano) |
| Assistant | editor UI chrome | SIL OFL 1.1 (The Assistant Project Authors) |
| Liberation Sans | server-side export metric substitute | SIL OFL 1.1 (Red Hat / Google digitized data) |
| Xiaolai SC | CJK fallback for the hand-drawn family | SIL OFL 1.1 (LXGW) |
| Helvetica | legacy normal — CSS name reference only, no binary shipped | n/a |
| Segoe UI Emoji | emoji fallback — CSS name reference only, no binary shipped | n/a |
| Noto Emoji | build-time asset for server-side export | SIL OFL 1.1 (Google) |
